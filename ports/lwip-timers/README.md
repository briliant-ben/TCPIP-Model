# Independent bounded data-timer observations

Uses pinned unmodified lwIP2.2.1 over the in-memory netif and the shared tcp-limited-transmit IR chain. The new public raw-API C driver extends the stream harness to at most12000ms and64 commands; every virtual millisecond invokes sys_check_timeouts before the next stimulus. TICK only advances this clock. No direct timer callback invocation, PCB timer/cwnd reads or mutation, upstream modification, host TCP or Linux execution. Actual output pbufs exclusively produce the captured local frames.

Other stream limits remain: <=16 total written bytes, <=64 peer bytes, no PSH/options/app.read, canonical handshake at0/10ms, scripted peer ACKs, COPY|MORE writes and explicit TRANSMIT. Initial overrides and synthetic drop plans are rejected. Withholding a scripted ACK is an unacknowledged-data experiment, not proof of a real peer loss channel. The model retains its exact timers; neither expected packets nor observed timestamps are rescaled or reordered.

RFC6298 June2011 §§2/3/4/5 provides RTO estimation/Karn, granularity and timer management: retransmit oldest unacknowledged data, exponential backoff and stop after full acknowledgment. The model's byte-age guards and original1000ms policy are shared, not reimplemented here. Upstream uses its own fixed configuration and250ms/500ms TCP timer quantization. Observe differences before attributing them to an RFC defect; do not infer internal RTO from one packet alone. Existing2750ms SYN-loss evidence remains separate and unchanged. Idle experiments likewise do not establish equal internal cwnd or initial-window policy.

Validation delegates the established stream evidence machinery through a private module instance: model/source/compiler/binary hashes, full-byte reference reconstruction, independent exported-query checks, raw checksum-valid capture, strict ordered0ms Difference, and receiver byte/EOF timing. New C/Python/schema/scope files and the shared stream verifier source are bound. Executed differences can be valid evidence; valid evidence is not conformance or a universal refinement proof. Binaries are rebuilt locally and excluded from commits.

Run `.venv/bin/python ports/lwip-timers/run.py`, then repeat with `--verify`; choose each input with `--scenario` and distinct `--out`. Standalone validation/fault/clock-granularity tests run with `.venv/bin/python ports/lwip-timers/tests.py`. Clock-schedule independence is a bounded driver test, not an unbounded scheduler proof. Rebuild evidence rather than weakening old hashes.
