# Historical and compatibility inventory

These items remain because the case study includes reproducible earlier
experiments and hash-bound evidence. This directory is an **index**, not a
relocated duplicate of those files. Their original paths are preserved.

| Existing path | Classification and maintenance rule |
|---|---|
| `protocol_lab/` | Frozen historical generic checker; selected files are pinned in `docs/frozen-legacy-framework.json`. New generic work belongs in Formal-Spec-Agent. |
| `agents/`, `deploy/` | Earlier protocol-specific job/deployment controllers; not the active reusable Agent framework. |
| `examples/`, `bindings/` | Earlier executable harnesses and codec bindings; the new reader entry is `code/` and `demo/`. |
| `model/tcp-*`, earlier component models | Scoped research/checkpoints, not additional authorities for the final composed subject. |
| `profiles.json`, `packet-profile.json`, `profiles` CLI | Historical profile acceptance channels and their original configuration. |
| `ports/`, `third_party/` | Real independent implementation/observation adapters and pinned upstream sources. Still needed for their named channels, not obsolete generated output. |
| `artifacts/` | Immutable evidence, original failures and explicit UNKNOWN/Differences; never a cache to delete or silently regenerate. |
| `docs/implementation-log.md`, `docs/github-handoff.md` | Chronological implementation/operator history, including old states and mixed languages. |
| [Old project overview](../docs/history/README-before-showcase.md), [formal history](../formal/history.md) | Earlier presentation preserved separately from current guides. |
| `pyproject.toml`, old Make targets | Compatibility metadata/commands for the original checkout, not the maintained framework package. |

Only the showcase surface is reorganized here. There are no duplicated models,
renamed oracle paths, altered raw receipts or changed historical hashes. Old
checkers should still use their original Git/source epoch. The two uncommitted
user-owned sent-ledger directories are not touched.
