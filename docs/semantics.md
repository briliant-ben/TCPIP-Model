# IR v0.1：执行语义与 TCP 切片

## 通用核心

存储格式采用 JSON，使用 Python 标准库即可读取。可读格式和编辑器可以后续增加；版本与执行语义才是后端之间的契约。

`ir_version=0.1`；`semantics=flat-efsm-atomic-ordered-v1`。这是平面 EFSM 子集。当前不支持 HSM、并发区域、历史状态或任意非确定性选择，不能把这些构造静默降级为普通 FSM。

v0.1 类型为 `bool`、`int`、`seq32`、`string`。`seq32` 可使用相等/不等和 `seq_add(seq32,int)`；加法模 `2^32`。整数 `le/ge` 不接受 `seq32`。v0.2 显式扩展下述数据语义；旧 v0.1 模型不自动获得新操作。

表达式 AST 支持字面值、`seq`、`var`、`event`、`state`、`timer_active` 和显式 `op/args`。guard 返回 bool。禁止 Python 代码、动态导入、文件访问或 eval。

## 一步执行

1. 外部事件的时间必须是单调的整数毫秒。
2. 注入外部事件前，先按截止时间执行到期定时器；相同截止时间按定时器名称排序。
3. 定时器与网络事件恰好同一时刻时，定时器先执行。这是确定性环境选择，不是 TCP 的唯一合法调度。
4. guard 使用当前状态、变量、事件参数和定时器集合求值。零条规则可用为 `Uncovered`；超过一条为 `Conflict`。
5. 定时器到期动作执行前移除该定时器；普通事件没有隐式取消行为。
6. action 按列表顺序执行，后续表达式看到之前的赋值。输出字段在 emit 时求值并固定。状态在 action 列表执行完成后切换到目标状态。
7. 检查变量类型和全部状态不变量，写出事件记录。`dispatch` / `tick` 操作全部成功后才提交；失败会回滚整个调用，调用者应终止该失败分支。

`arm` 启动或替换定时器，延迟必须为正整数；`cancel` 取消不存在的定时器无副作用。定时器事件由运行时生成，禁止外部伪造。

不变量在初始状态和每个已完成的事件后检查，当前没有中间 action 不变量或时序逻辑。输出包正确性另由独立手写预期值、编码校验测试覆盖；状态不变量并未证明所有输出字段正确。

## TCP 配置

建模一个端点的主动打开，连接四元组、权限、路由与资源分配均假定有效。`net.synack` 是**抽象事件**：适配层应保证匹配连接，SYN/ACK 置位，RST/FIN 未置位，无 payload，报文格式与校验和有效。该事件的 `seq` 和 `ack` 字段仍由 IR 处理。

不发送 SYN data，所以可接受的 SYN+ACK 在此范围内需精确确认 ISS+1。这个 guard 不能直接推广到支持 SYN data 的完整 TCP。非法 ACK 当前会产生模型覆盖缺口，尚未实现其 RST/丢弃等处理。

选择初始 RTO=1000 ms 和指数退避，代表 RFC 6298 的一个算法配置；不是所有实现都必须采用相同初值。重传不推进 SND.NXT；握手完成后取消 SYN 重传定时器。`retries` 是已发生重传次数，未实现最大重试次数、用户超时或重试耗尽的 CLOSED 路径。

ESTABLISHED 是本切片终点。`rto_ms` 是 SYN 阶段的退避值，终点之后不驱动数据传输。RFC 6298 §5.7 的握手后数据 RTO 处理、RTT 采样及 Karn 算法均未实现；因此本模型不能作为完整 RTO 实现使用。

固定初始 ISS 仅为可复现实验，并未建模实际 ISS 选择算法。JSON 里的普通整数值依照字段类型解释；表达式里的序列常量用 `{"seq": number}` 区分普通整数。

## 网络、丢包与观测

环境在场景中显式列出何时投递 SYN+ACK。丢包通过“不提供该次 SYN 对应的响应”体现；`drop_outgoing` 是环境注释，并会校验指向的输出包确实存在、为 SYN。当前没有独立运行的对端或网络队列，注释不是通用网络仿真器。

合成 PCAP 的观测点是本地端点的出口和入口，因此丢失的初始 SYN 仍在 PCAP 中可见。PCAP 不编码 drop 元数据，drop 标注保存在 `packet-map.json` 中。地址为文档地址 192.0.2.1/192.0.2.2，端口为 40000/8080，均为编码配置，不是 IR 状态。

比较器采用本切片的有序投影：direction、flags、seq、ack、time_ms。忽略窗口、选项及 IP 字段；时间默认容差 50 ms。必须先对真实序列号、时间原点和观测点做归一化。它不判断完整 TCP 行为，不支持一般非确定轨迹接受关系。

## 来源与义务

每个 transition 和 invariant 指向 requirement ID，requirement 记录官方条款链接、人工解释、义务强度和类别。`PROFILE-SCOPE` 是环境假设，不是 RFC 要求；不变量是工程推导，关联的条款不是对该公式的逐字规范表述。

RFC 原文与 manifest 中 SHA-256 一起固定。下载日期表示取回基线的日期；尚未进行独立 errata 清单审查或标准更新监控。保存的 RFC 保留其原始版权及法律声明。需求解释不修改原文。

当前没有自动 RFC 提取、规范覆盖率百分比、guard 全局完备性证明或 SHOULD 例外推理。JSON 静态校验与有界探索只是其中两道检查。

## v0.2 独立检查与观测

Z3 后端另行编码此 IR 子集，覆盖符号化 32 位 ISS、带类型的事件字段和整数时间。它检查已定义路径的有界状态安全与 guard 重叠，不通过假定不变量成立来筛掉失败路径；正定时器延迟是额外的运行时安全条件。详见 `formal/README.md`。

PCAP 归一化器不调用合成编码器。它按显式四元组过滤连接，保留包顺序，将真实双端 ISS 映射到模型序列空间，以第一个选中 SYN 为时间原点。它支持经典 PCAP 的 IPv4/TCP active-open 切片，拒绝选中连接的分片、payload、额外控制 flags 和无效格式；不做去重、TCP 重组或通用抓包语义推断。

`assess` 对构建快照和外部证据分别校验。语义文档、RFC manifest、IR、运行时代码或场景改变会使旧构建失效。观测还绑定一次成功的 packetdrill 运行，不能把旧抓包和新运行记录直接组合成通过。哈希用于检测过期或内容变化，不为操作者声明的来源提供真实性证明。

## v0.2 数据语义（保留原 EFSM 提交顺序）

模型使用 `ir_version=0.2`，仍采用 `flat-efsm-atomic-ordered-v1`。新增类型和操作在 v0.1 模型中显式拒绝；不改变两个旧模型的规则或版本。

`bytes` 是有限八位无符号整数序列，JSON 值为 `[0,128,255]`，表达式常量为 `{"bytes":[0,128,255]}`。不是 Unicode 文本、十六进制字符串或任意 Python 对象；拒绝 bool、负数和大于 255 的元素。初值、事件、赋值、输出和轨迹快照具有值语义，调用者修改输入列表不影响已提交状态。缓冲容量由模型 guard 和不变量显式限定；类型本身不隐含协议容量或丢弃策略。

| 操作 | 类型与精确结果 |
|---|---|
| `bytes_len(b)` | bytes → int，八位组数 |
| `bytes_concat(a,b)` | bytes × bytes → bytes，按序连接 |
| `bytes_slice(b,offset,count)` | bytes × int × int → bytes，截断切片；offset/count 分别取 max(0,x)，从 offset 取至多 count 字节；越尾截断，越界起点返回空串 |
| `sub(a,b)` / `min(a,b)` | int × int → int，无界数学整数减法/最小值 |
| `ite(condition,yes,no)` | bool × T × T → T；两个分支必须同型，选择对应值；无隐式类型转换 |
| `seq_distance(a,b)` | seq32 × seq32 → int，`(b-a) mod 2^32`，从 a 到 b 的前向距离，不是带符号减法 |
| `seq_comparable(a,b)` | bool，当且仅当距离不等于 `2^31` |
| `seq_lt(a,b)` | bool，当且仅当 `0 < distance < 2^31` |
| `seq_le(a,b)` | bool，当且仅当 `0 <= distance < 2^31` |

切片是总函数，负索引没有 Python 从尾部计数的含义。需完整读取 count 字节的模型必须用 guard/不变量约束 offset、count 和长度，不得依赖切片抛异常来限制输入。空串参与相等、长度、拼接和切片均有定义。

`ite` 在 IR 0.2 中可用；与其他操作一样，纯表达式参数按现有方式先求值，因此没有短路或 action 副作用。两个分支都必须通过静态类型检查。返回的 bytes 继续遵守赋值、emit 与快照的值语义；旧版 IR 不自动获得该操作。独立 Seq 后端用同型 Z3 If，长度投影用同一条件选择分支长度，并另行检查 `len(If(c,a,b))=If(c,len(a),len(b))` 的全序列义务。

序列谓词在相距恰好半空间时双向 lt/le 均为 false，comparable 为 false；这是显式的“不可比”，不是选定任意方向。比较不是全局传递的整数排序。建模窗口及在途范围必须小于半空间，并按同一基准使用前向距离；未知/歧义输入应在 IR 中有明确处理或报告未覆盖。`seq_add` 继续接受任意整数增量并取模（包括负增量），没有暗中加入窗口约束。

规范追溯：RFC 9293 §3.4 固定 32 位模运算、累计确认及接收区间；§3.10.7.4 规定 ESTABLISHED 中 ACK/窗口处理。半空间不可比是 IR 的显式建模契约，RFC 1982 §3.2 仅作通用串行数比较的参考（其直接对象是 DNS，不宣称为 TCP 的附加 MUST）。当前 TCP 规范基线仍是仓库已哈希的 RFC 9293/6298，未更换原文。

独立 Z3 后端将 bytes 编码为 `Seq(BitVec(8))`，序列号仍是 BV32，长度/offset/count 为数学整数；用 SubSeq 和显式非负截断编码切片，ULt 编码半空间谓词，BV2Int 编码前向距离。不调用参考求值器构造约束。支持的 AST 必须逐项翻译，未知操作显式拒绝。复杂的序列/整数/位向量混合查询可能返回 unknown；unknown 不得提升为 bounded_pass。该扩展仍无无界证明、跨连接组合或默认有限容量假设。

## v0.2 声明式模型组合

`load()` 可解析同目录下的相对 `extends` 基模型（可递归，禁止目录逃逸和循环）。requirements、variables、events、messages、timers 按名称合并；同名项由 overlay 完整替换，不能隐式深合并字段。states、scope 和其他标量/列表由 overlay 整体替换。transitions/invariants 默认保留基模型并追加；`remove_transitions`/`remove_invariants` 必须逐项列出已有 ID，未知 ID 拒绝。

`amend_transitions` 每项以唯一 ID 指定已有规则，可提供 `and_guard`（与原 guard 做显式 and）和 `append_actions`（在原 actions 后按序执行）；禁止回调或未知补丁操作。组合后删除组合元数据，对整个展开模型执行相同的类型、规则及不变量校验。调用者不能将未展开 overlay 直接传给 Machine/形式后端。

组合是通用 IR 加载机制，不添加协议事件、序列号转换或定时器调度。suite 保存 expanded-model.json 并将所有基模型和 overlay 纳入输入哈希；模型语义哈希针对展开后的 IR。连接规则变更会使组合模型旧证据失效。

Profile 的 `scenarios` 可为一个目录字符串或多个目录字符串组成的列表，用于复用原有回归输入。目录必须位于仓库内，跨目录重复场景 ID 明确拒绝；所有实际输入文件均进入哈希绑定，不通过复制/改写旧证据伪造复用。

## 独立归纳义务的可选编码

`inductive` 路径可对不观察字节内容的性质使用精确长度投影，并用完整 32 位取值域的模整数表示序列号。字节内容 eq/ne 明确拒绝，不能转为长度比较；原完整 Seq(BV8)/BV32 BMC 与场景重放保持不变。长度拼接/切片公式另有全序列 SMT 义务。归纳前状态假设全部不变量，后状态不假设；必须分别通过初值成立、每条规则保持、每组 guard 不重叠以及非空完整字节见证重放。报告、支持范围和任意前状态反例的分类见 `docs/inductive.md`，不得把归纳义务结果冒充原 BMC 的结果或完整协议证明。
